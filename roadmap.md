# Axelmann Auto — Roadmap

## Done (phase 1: buyer-facing core)

- Showroom Ink design system (tokens, fonts, radii) in `src/styles.css`
- Global header / footer / trust strip
- Homepage: hero with Buy / Sell / Finance intents, AI-ready search, featured inventory
- Buy: search results with filter rail (condition, city, body, fuel, price, monthly)
- Vehicle detail: gallery, cash vs monthly price, inspection summary, specs, actions
- Sell my car: guided steps with AI valuation estimate

- Multi-country config (currency, VAT, languages), Arabic RTL, admin panel
- Favorites, saved searches, price-drop alerts, notifications
- SEO landing pages by brand / city / body type / budget; content portal
